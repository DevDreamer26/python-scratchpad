## 🛠️ Local

Want to clone this repo and run any of the practice scripts locally? Drop these lines into your terminal:

```bash

git clone [https://github.com/DevDreamer26/python-scratchpad]

# Jump into the directory
cd python-scratchpad

# Run a LeetCode problem script
python3 leetcode/two_sum.py
```
